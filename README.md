# 2KH1 (가제)

**한국어 미스터리 비주얼 노벨**

> 🚧 개발 중입니다. 이 문서는 임시로 작성되었으며 출시 전에 다시 정리합니다.

사라진 친구가 마지막으로 남긴 흔적을 따라가는 이야기입니다.
인물들과 대화하고, 장소를 직접 조사하고, 모은 단서로 추리해 진실에 다가갑니다.
선택과 추리 결과에 따라 결말이 달라집니다.


---

## 게임 특징

- **대화**
  - 대본을 따라 진행되는 이야기와 선택지, 여러 갈래의 결말
  - 다른 인물의 대사는 그 인물 옆 말풍선으로, 주인공의 생각과 나레이션은 아래 대화창으로
  - 자동 진행, 읽은 대사 건너뛰기, 지난 대사 다시 보기
- **조사**
  - 장소 화면에서 수상한 곳을 직접 눌러 살펴보기
  - 서류와 사진은 크게 펼쳐 확대해 읽기
- **수첩 · 가방 · 휴대폰**
  - 조사한 내용이 수첩에 자동으로 정리됨
  - 가방의 아이템을 확인하고 서로 조합하기
- **추리와 긴장감**
  - 모은 단서로 답을 고르는 추리 장면
  - 제한 시간 안에 움직여야 하는 장면과 미니게임
- **저장**
  - 이야기의 정해진 지점에서 저장하고 이어하기

## 조작법

| 키 | 동작 |
|---|---|
| 마우스 클릭 · 스페이스 · 엔터 | 다음 대사 |
| ↓ | 대화창 숨기기 / 다시 보기 |
| ↑ | 지난 대사 보기 |
| ← → | 자료 · 수첩 장 넘기기 |
| 숫자 1 ~ 9 | 선택지 고르기 |
| Esc | 열린 창 닫기 |

## 개발 환경

| 항목 | 내용 |
|---|---|
| 엔진 | 유니티 6 (6000.5.7f1) |
| 화면 | 1440 × 1080 (4:3) |
| 언어 | C# |

> 그림 · 소리 · 대본 파일은 이야기 내용 보호를 위해 이 저장소에 포함하지 않습니다.
> 그래서 저장소만 내려받아서는 게임을 실행해 볼 수 없습니다. 출시 후 체험판 링크를 이곳에 추가할 예정입니다.

## 폴더 구성

```
Assets/
├─ Scenes/              시작 화면 · 본편 · 이어하기 · 설정 화면
├─ Scripts/
│  ├─ Common/           게임 시작 준비, 그림 배치, 글꼴
│  ├─ Dialogue/         대사 · 말풍선 · 무대(배경과 인물) · 조사 · 추리 · 미니게임
│  ├─ Save/             저장과 이어하기
│  └─ UI/               수첩 · 가방 · 휴대폰 · 설정 · 자료 보기 · 공용 화면 부품
├─ Editor/              개발용 도구 (그림 위치 잡기 등)
└─ StreamingAssets/     이야기 내용이 없는 공용 데이터 (그림 좌표, 장면 구성)
```
